# 包装膜材料成本优化与智能体系统方案（V3）

日期：2026-09-16　　适用：内部执行版

## 0 现状与目标（统一口径）

- 现用配方：LLDPE 60% + LDPE / HDPE / 再生一级料 40%。**LLDPE 约 12,000 元/吨，是成本大头**（60% 用量 ≈ 每吨配方 7,200 元）；再生料约 8,000 元/吨。
- 红线：拉伸、撕裂、穿刺、热封、透明度五项均不低于现用膜（base）。
- 目标分两层：
  1. 材料层：找到能替代现用 LLDPE / HDPE、性能相近、价格更低的材料，并确定再生料可加到多少。
  2. 系统层：建成智能体，输入材料信息（性能参数 + 价格）就能自动给出最优材料组合方案，价格变了方案自动更新。
- **当前重心：把智能体需要的数据基础做扎实**（材料库、再生料数据、价格表、性能基线、证据），再进入实验验证。

## 1 三条降本路线与验证方法

### 1.1 提高再生料比例

- 做法：固定其他组分，再生料按阶梯 15% → 25% → 35% → 45% 试；每档配 PPA + 抗氧剂母料 1%，整轮用同一批再生料并留样。
- 要采的数据：再生料来源（工业膜回料 / 消费后料）、等级、MFR、密度、灰分、凝胶数、气味、批次差异；每档的五项实测。
- 判据：五项 ≥ base；出现晶点、雾度上升、热封下降的那一档即为上限。
- 预期：每提高 10 个点再生料（替代 LLDPE），原料成本约降 400 元/吨（按 12,000 − 8,000 计）。

### 1.2 筛选 LLDPE / HDPE 替代品

按"性能相近、价格更低"用性能窗口筛，不凭印象：

| 筛选维度 | 现用 LLDPE 的窗口（待用实测校正） | 说明 |
|---|---|---|
| 密度 | 0.915～0.925 g/cm³ | 决定挺度、透明、热封 |
| 熔点 / Vicat | 118～126 ℃ | 决定热封温度与耐热 |
| MFR（190/2.16） | 0.5～3 g/10min | 吹膜可加工窗口 |
| 共聚单体 | C4 / C6 / C8 | C6/C8 韧性更高，可减量 |
| 落镖 / 穿刺 | ≥ 现用牌号 TDS 值 | 韧性来源 |
| 价格 | < 12,000（目标 ≤ 10,000） | 含税到厂 |

候选池（按"替代什么"分组）：

1. **同类更便宜的 LLDPE**：国产 C4（7042 类，市价通常远低于 12,000）、国产 C6、副牌 / 宽规格料（比正牌低 10%～30%）。
2. **高效韧性树脂低比例替代**：茂金属 LLDPE（C6/C8）、POE——单价高但用量少，用 10～15% 顶替 25～30 个点的现用料。
3. **HDPE 的替代或去除**：MDPE、直接去掉 HDPE（透明产品里 HDPE 拖累撕裂与雾度）。
4. **再生线性料**（工业膜回料）：补韧性且便宜，须无 PIB。
5. **LDPE 部分替代**：再生高压料替换新料 LDPE。

流程：TDS 参数入库 → 窗口过滤 → 价格排序 → 文献/专利证据核对（对五项性能的影响方向）→ 向供应商要样料与报价 → 小试。

### 1.3 组合方案

再生料 + 替代树脂 + 助剂的组合由智能体在约束内生成（合计 100%、LDPE 类 ≥ 35% 稳泡、HDPE ≤ 5% 等），按成本排序、按证据给定性预期，输出 Top 20 与首轮试验清单。

## 2 智能体所需的数据基础（当前重心）

### 2.1 材料数据库（每种牌号一条，字段固定）

| 字段组 | 字段 | 来源与要求 |
|---|---|---|
| 标识 | 代码、类别、名称、牌号、生产商、供应商 | — |
| 物性 | 密度、MFR、熔点 / Vicat、共聚单体、分子量分布（宽/窄）、是否再生 | 供应商 TDS，标出处链接 |
| 膜性能（TDS 典型值） | 落镖、拉伸 MD/TD、撕裂 MD/TD、雾度、光泽、热封起始温度 | TDS；缺失写"待测" |
| 加工 | 推荐加工温度、吹膜适用性、是否需 PPA | TDS / 应用指南 |
| 对五项性能的影响 | 方向 + 幅度等级 + 依据（文献 / 专利 / TDS / 经验） | 每条带 [S#] 出处 |
| 用量 | 典型用量范围、上限原因 | 文献 / 经验 |
| 价格 | 估计价（来源、日期、口径）、实价（供应商、起订量、报价日期） | 两档分列 |
| 风险 | 货源、批次、加工、气味、法规 | — |

验收：首版 ≥ 40 个牌号（其中现用 4 种必须齐全）、每条物性有 TDS 出处、每条价格有日期与来源。

### 2.2 数据来源与采集方式

| 来源 | 内容 | 方式 |
|---|---|---|
| 供应商 TDS / 产品页 | 物性、典型膜性能、加工建议 | 网页搜索抓取 + 手动上传 PDF |
| 学术文献（OpenAlex / Crossref / Scopus） | 共混机理、再生料影响、茂金属减量、工艺影响 | 自动检索 → LLM 判相关 → 文献卡 |
| 专利（Google Patents） | 配方范围、声称效果、规避点 | 自动抓全文 → 专利卡 |
| 中文文献（CNKI / 万方） | 工程实践、配方比例 | 手动下载上传（无开放接口） |
| 价格网站（生意社 / 卓创 / 隆众）+ 供应商报价 | 参考价与实价 | 自动抽取（标日期）+ 采购回填 |
| 甲方 | 现用牌号、实际进价、现用膜实测 base | 询价清单 + base 测试表 |

规则：可信度 实验 > TDS > 期刊 > 专利 > 行业网 > 论坛；数值只能来自 TDS / 文献 / 实价，模型只给方向。

### 2.3 再生料专项数据

- 供应商清单（≥ 3 家）、等级（一级透明 / 二级 / 线性回料 / PCR）、来源膜种、价格、起订量。
- 进厂快检项：MFR、密度、灰分、水分、DSC 杂质峰（PP/PA/PET）、凝胶数；每批一条记录。
- 目的：让"再生料比例上限"与"批次波动"成为可量化的输入，而不是经验。

### 2.4 价格表与联动机制

- 价格表两档：估计价（网查，带来源与日期）/ 实价（采购回填）；成本计算优先用实价。
- 更新频率：估计价每周自动刷新一次；实价随询价回填。
- 联动：价格变动 → 全部配方成本重算 → Top 20 重排 → 标出排名变化 > 3 位或成本变动 > 100 元/吨的方案。
- 现用 LLDPE 12,000、再生料 8,000 先作为"甲方口述价"录入；LDPE / HDPE 的实价待补。

### 2.5 性能基线与判据

- base = 现用膜五项实测均值 ± SD（现用膜 2 卷、同批），另测厚度、落镖、热封窗口。
- 过关：力学 / 热封 ≥ base × 0.95 且 ≥ base − 1SD；雾度 ≤ base + 1；透光率 ≥ base − 1%。
- 没有 base 之前，智能体只能出"定性预期"，不能判过关——这是数据基础里最先要补的一项。

### 2.6 数据基础阶段的交付物

材料数据库 V1（xlsx + 系统内）、再生料数据表、价格表 V1、来源清单、文献卡 / 专利卡 / 材料卡、现配方机理报告、base 测试方案与数据表模板。

## 3 智能体系统设计

### 3.1 输入 / 输出

- 输入：① 目标膜（产品、膜厚、透明 / 非透明、单层 / 三层、五项要求或 base）；② 可用材料清单（含物性与价格，可随时增删）；③ 约束（配方边界、成本上限、替代意愿）。
- 输出：按成本排序的材料组合方案，每条含：各组分比例、成本（估 / 实口径）、五项定性预期与依据、风险与观察点、建议试验顺序；价格更新后自动重排。

### 3.2 推荐逻辑（两阶段）

- 无实验数据时（知识驱动）：材料窗口筛选 → 约束内生成候选 → 按价格表算成本 → 用材料卡 / 文献卡做定性五项评估 → 按"降本额 × 过关把握"排序 → Top 20 + 首轮试验清单（覆盖不同思路，兼顾建模补点）。
- 有实验数据后（数据驱动）：每项性能单独建模（Scheffé / 梯度提升 / 高斯过程，留一交叉验证）→ 扫描候选空间（配方库 + 约束内随机 2000 个）→ P(五项过关) ≥ 0.8 下取成本最低 → 利用型 + 探索型推荐 → 知识库复核化学合理性 → 下一轮实验 → 回灌。
- 停止条件：连续两轮最优过关方案成本改善 < 50 元/吨。

### 3.3 价格联动

价格表是唯一成本来源；任何价格变更（手工登记、询价回填、每周自动抓取）都触发：成本重算 → 排名更新 → 变化提示。方案永远带"价格口径与日期"。

### 3.4 与实验的闭环

首轮：再生料阶梯 4 档 + 替代树脂代表方案 6～8 个 + D-最优补点 → 24～30 个配方；同机台同工艺；数据按统一表回灌；建模后扫描推荐；每轮 1～2 周。

## 7 风险与对策

| 风险 | 对策 |
|---|---|
| 12,000 的 LLDPE 若是特殊牌号（如茂金属 / 进口），"替代"实际是降规格 | 先弄清现用牌号定位，窗口筛选以其 TDS 为基准，性能红线兜底 |
| 再生料批次波动污染数据 | 整轮同批次、留样、批次入表、进厂快检 |
| 网查价格与实价差距大 | 偏差 > 40% 不自动采用；实价优先；报价带日期 |
| 没有 base 就急着判过关 | 第 1～2 周内完成 base 测试；之前只出定性预期 |
| 文献 / 专利体系与本产品不同 | 只作先验与方向，不直接进训练集；过关以实测为准 |
