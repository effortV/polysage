# Processing Stabilization of Polyolefin Recyclates Using Alditols in Combination 

- 类型：literature
- 来源：Processing Stabilization of Polyolefin Recyclates Using Alditols in Combination With α-Tocopherol: A Sustainable Alternative to Phosphites（scopus，2026）https://doi.org/10.1002/vnl.70076

## 出处
Ng K.H., Journal of Vinyl and Additive Technology, 2026, 10.1002/vnl.70076

## 研究体系
材料：聚烯烃回收料（多种牌号）；工艺：多次挤出加工；膜厚：资料未提供

## 结论（只记与本项目有关的）
- 定性：将醛糖醇与α-生育酚组合作为生物基稳定剂体系，可替代传统亚磷酸酯添加剂用于聚烯烃回收料的加工稳定化。
- 定性：该新型稳定剂体系在多次挤出过程中，在熔体稳定性、抗氧化性和分子量保持方面表现出优于传统亚磷酸酯体系的性能。
- 定性：稳定剂组分之间存在明显的协同效应。
- 定性：在醛糖醇衍生物中，基于己六醇的体系表现出最佳的综合性能。

## 与本项目的关系
本研究虽未直接涉及聚乙烯吹塑膜配方，但提供了用低成本、可持续的生物基稳定剂（醛糖醇+α-生育酚）替代传统亚磷酸酯的可行方案。若本项目所用再生料在多次加工中面临热氧降解导致性能下降的问题，可借鉴此新型稳定剂体系来提升再生料的加工稳定性，从而可能允许提高低成本再生料的添加比例，实现降本目标。
