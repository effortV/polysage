# Implementation of Machine Learning in Flat Die Extrusion of Polymers

- 类型：literature
- 来源：Implementation of Machine Learning in Flat Die Extrusion of Polymers（openalex，2025）https://doi.org/10.3390/molecules30091879

## 出处
Nickolas D. Polychronopoulos, Ioannis E. Sarris, J. Vlachopoulos, Molecules, 2025, 10.3390/molecules30091879

## 研究体系
研究体系为聚合物平模挤出（片材与薄膜），通过计算机模拟生成包含模头几何（限流棒下方间隙）、聚合物流变与热物理性质、加工条件（产量、温度）变化的200个案例数据集。膜厚资料未提供。

## 结论（只记与本项目有关的）
- 定性：机器学习方法有潜力减少甚至消除平模挤出中的试错过程。
- 定性：SHAP分析揭示了聚合物流变性、产量和限流棒下方间隙对预测目标（厚度变化、压降、最低壁面剪切速率）的关键影响。

## 与本项目的关系
本研究聚焦于平模挤出工艺的模拟与机器学习预测，未涉及聚乙烯吹塑膜的具体配方或成本。其可借鉴之处在于，未来可考虑采用类似的模拟与数据驱动方法，对吹膜工艺中不同配方（如提高再生料比例）的加工窗口和薄膜厚度均匀性进行预测，以减少试错成本。
