# The interplay between macromolecular structure, rheology, processing condition, 

- 类型：literature

## 出处
Amir Bashirgonbadi, Laurens Delva, Elise Caron, Flávio H. Marchesini, Kevin M. Van Geem, Kim Ragaert, Polymer, 2023, 10.1016/j.polymer.2023.126566

## 研究体系
材料：(线性)低密度聚乙烯 ((L)LDPE)；工艺：吹膜 (film blowing)；膜厚：资料未提供

## 结论（只记与本项目有关的）
- 该研究旨在揭示大分子结构、流变行为、加工条件与最终薄膜性能之间的相互作用（定性）
- 提出了一个量化吹膜过程中可加工性（processability）的框架，并将其与分子量（分布）和拉伸流变行为相关联（定性）
- 选定的加工条件与薄膜的结晶形态和性能存在关联（定性）
- 该研究为未来涉及更复杂聚合物体系（如共混物和受污染回收料）的研究提供了基础参考（定性）

3

## 与本项目的关系
本研究为纯 (L)LDPE 的吹膜工艺提供了基础性理解，可作为评估本项目中使用再生料及混合料配方时，工艺参数与薄膜性能关系的理论基线。文中提出的可加工性量化框架及对复杂体系（如共混物、回收料）的展望，直接指向了本项目降本配方的核心挑战。
